# MM2 Vault — Cart & Dashboard Demo

A responsive, front-end-only MM2 collectible storefront concept. Built as a demonstration of shopping cart behavior, catalog management, and a simple admin dashboard.

## Features
- MM2 demo catalog with category filters, search, and sorting
- Add/remove cart items and adjust quantities
- Stock-aware cart validation and automatic stock reduction after demo checkout
- Dashboard overview for products, stock, demo orders, and simulated revenue
- Add, edit, and delete catalog items
- Dark/light theme toggle
- Local browser persistence using `localStorage`
- Responsive layout for mobile and desktop

## Run locally
Open `index.html` in a browser. No build step or package installation is required.

## Important
This is a UI/UX demonstration only. It does not connect to Roblox, a database, payment provider, or real order fulfillment. Data is stored only in the current browser. Product names and sample prices are fictional examples for the demo.

Unofficial fan-made concept; not affiliated with Roblox or the Murder Mystery 2 developers.
